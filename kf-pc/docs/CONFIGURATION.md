# PC 配置说明

本项目只保存公开前端配置。数据库密码、JWT 密钥、模型密钥、微信和云存储凭据均在 Core 中配置，不要填入任何 `VITE_*` 变量。

## 环境文件

从 `.env.example` 复制 `.env.development` 供 `pnpm dev` 使用；复制 `.env.production` 供 `pnpm build:prod` 使用。环境值在构建时写入页面，部署后修改文件需要重新构建。真实环境文件已被 `.gitignore` 排除。

| 变量 | 示例/默认 | 用途 |
| --- | --- | --- |
| `VITE_API_BASE_URL` | `/api/v1` | 浏览器业务接口前缀；客服模块可在公共请求器中切到其对应版本 |
| `VITE_API_PROXY_TARGET` | `http://127.0.0.1:3000` | 本地 Vite 的 `/api` 代理目标；生产需由托管服务另配代理 |
| `VITE_DISPATCH_BASE_URL` | `http://127.0.0.1:5174` | 任务派发时生成的 H5 入口，部署后改为自己的 H5 公开地址 |
| `VITE_ASSET_BASE_URL` | 空 | 后端返回相对文件路径时使用的公开根地址；空值表示同源。独立后端可填 `http://127.0.0.1:3000` 等自己的文件服务根地址 |

API 已返回完整 HTTPS 文件地址时保持该地址；相对 `/uploads/...` 需由同源站点代理，或填写文件服务根地址。文件 URL 是否允许访问仍由后端鉴权和存储策略决定。

## 账号和租户

后台登录使用自行创建的 Core 管理员。登录成功后由服务端返回可用租户和权限，前端不附带固定租户。切换账号/租户会更新请求上下文；访问权限还必须由后端验证。

## 模板和官网内容

原 Excel 文案、重复文件和外部合作名单已移出。每日任务的“下载模板”动态生成带“类型、评论内容、配套回复序号、配套回复、发布建议”表头的空白工作簿；填写自己的内容后再导入。官网内容从空白状态开始，自行填写文案并上传有权使用的图片。

## 配套和验收

使用同批次 Core、H5 与机器人副本进行联调，先完成管理员登录、权限和租户检查，再做一个测试任务的创建、领取、证明提交和审核闭环。提现需要单独配置并验收后端支付服务。没有任何原业务账号、云服务或平台授权随本项目提供。
