## 自行复查

```bash
python3 -m unittest discover -s tests -v
```

如需运行机器人离线单测，可在独立 Python 3.12 虚拟环境安装轻量测试依赖：

```bash
python -m pip install requests openpyxl python-dateutil tzdata
python scripts/test_bots_offline.py
```

该入口复制到临时目录运行，排除本地会话与状态目录，并禁止测试中的网络连接。它不启动 Qt 界面或平台浏览器。各 Web 项目另执行本目录 README 中的构建命令。

仓库包含 GitHub Actions 检查流程，但本轮尚未在 GitHub 上触发该流程。

## 仍需使用者环境验收

- 空数据库迁移、初始化、真实登录与已有数据库升级。
- PC、H5、后端之间的权限、任务、团队、审核与账目闭环。
- 真实模型、Coze 工作流、短信、微信授权、分享及付款。
- 平台当前页面的采集、自动回复、主动私信、重启恢复和多账号隔离。
- Qt 界面、Windows 安装包、macOS 应用、浏览器和语音模型的运行及分发。

这些结果支持源码展示和继续开发，不代表已经完成跨系统生产验收。
